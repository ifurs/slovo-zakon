# Слово — закон

Браузерна головоломка: правила гри складено зі слів на полі, і ці слова можна штовхати.
`ЇЖАК ЦЕ ТИ`, `ЯБЛУКО ЦЕ ПЕРЕМОГА`, `СТІНА ЦЕ СТОП` — розірви чи склади речення, і світ зміниться.

## Запуск

ES-модулі не працюють через `file://`, тому потрібен локальний сервер:

```bash
npm start            # python3 -m http.server 8137
```

Відкрий http://localhost:8137

## Керування

Стрілки / WASD — рух · Пробіл — чекати · Z — скасувати · R — заново · Esc — рівні · M — звук.
На телефоні — свайпи або екранний джойстик.

## Слова

| Іменники | Властивості |
|---|---|
| ЇЖАК, СТІНА, ЯЩИК, ЯБЛУКО, ВОДА, ВОГОНЬ, КЛЮЧ, ДВЕРІ, ДЕРЕВО, КАМІНЬ, ЛИС, ГРИБ, ЛІД, ЛИСТ, СЛОВО | ТИ, ПЕРЕМОГА, СТОП, ШТОВХ, СМЕРТЬ, ВИР, ВІДМИЧКА, ЗАМОК, РУХ, ЖАР, ТАНЕ, ВИБУХ, ЗГРАЯ, ЕХО, СЛІД |

`ЦЕ` поєднує іменник із властивістю або з іншим іменником (перетворення), `І` — кілька слів разом.
`СЛОВО` означає самі плитки зі словами: `СЛОВО ЦЕ ТИ` — і ти керуєш правилами напряму.

### Власні механіки

- **ВИБУХ** — вибуховий предмет, на клітинці з яким опиняється ще щось, знищує все в квадраті 3×3,
  навіть слова. Інші вибухові предмети поруч вибухають ланцюжком.
- **ЗГРАЯ** — коли рухається один предмет зграї, крок у той самий бік роблять усі предмети цього виду.
- **ЕХО** — предмет повторює твій попередній хід, на хід пізніше.
- **СЛІД** — предмет лишає за собою ЛИСТ; правила на кшталт `ЛИСТ ЦЕ СТОП` перетворюють слід на стіну.

## Структура

- `src/engine.js` — логіка правил і ходів (без DOM, працює і в Node)
- `src/levels/chN.js` — рівні, по файлу на розділ; `src/levels/README.md` — легенда карт і правила дизайну
- `src/levels.js` — збирає розділи докупи
- `src/render.js` — малювання на canvas
- `src/main.js` — інтерфейс, керування, прогрес (localStorage)
- `tools/solve.mjs` — пошук найкоротшого розвʼязку, `tools/replay.mjs` — програти ходи й намалювати поле
- `tests/` — тести рушія і перевірка розвʼязку кожного рівня

```bash
npm test                                  # усі тести
node tools/solve.mjs 2 4                  # найкоротший розвʼязок рівня 4 розділу 2
node tools/replay.mjs 2 4 "UURR..."       # програти ходи (без ходів — збережений розвʼязок)
```

Кожен рівень зберігає свій `solution`; `npm test` перевіряє, що він виграє.
